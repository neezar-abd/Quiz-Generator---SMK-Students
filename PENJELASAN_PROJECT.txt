2.3 FLOW DATA SAAT GENERATE QUIZ
---------------------------------
1. User upload file di halaman /upload
2. File divalidasi (tipe, ukuran, format)
3. File dikirim ke API /api/generate-quiz
4. API extract text dari file:
   - PDF → gunakan PDF parser
   - Word/PPT → gunakan library khusus
   - Image → gunakan OCR (Optical Character Recognition)
5. Text dikirim ke Google Gemini API
6. Gemini menganalisis text dan generate soal dalam format JSON
7. API validasi response dari Gemini
8. Soal disimpan ke database PostgreSQL
9. User redirect ke halaman kuis

B) ADAPTIVE LEARNING ALGORITHM
-------------------------------
Purpose: Adjust difficulty based on user performance

Algorithm:
1. Track user answers (correct/incorrect)
2. Calculate performance metrics:
   • Accuracy rate (% correct)
   • Response time (future)
   • Streak (consecutive correct)
3. Determine next question difficulty:
   • High accuracy (>80%) → increase difficulty
   • Medium accuracy (50-80%) → same level
   • Low accuracy (<50%) → decrease difficulty
4. Select question from pool matching difficulty
5. Avoid recently asked questions

Implementation:
```typescript
function getNextDifficulty(
  userAnswers: UserAnswer[]
): 'easy' | 'medium' | 'hard' {
  const recent = userAnswers.slice(-5); // Last 5 answers
  const accuracy = recent.filter(a => a.isCorrect).length / recent.length;
  
  if (accuracy > 0.8) return 'hard';
  if (accuracy > 0.5) return 'medium';
  return 'easy';
}
```

BAGIAN 4: TROUBLESHOOTING & FAQ
================================================================================

4.1 COMMON PROBLEMS
-------------------

Q: Quiz generation fails dengan "AI service unavailable"
A: Check GEMINI_API_KEY di .env.local, pastikan valid dan belum expired

Q: Database connection error
A: Periksa DATABASE_URL, pastikan Supabase project aktif

Q: Login dengan Google tidak berfungsi
A: Verify GOOGLE_CLIENT_ID dan GOOGLE_CLIENT_SECRET, pastikan 
   authorized redirect URI di Google Console sudah benar

Q: File upload gagal
A: Check file size (<10MB) dan format (PDF, DOCX, PPT, Image)

Q: Hydration error di console
A: Clear browser cache, restart dev server
